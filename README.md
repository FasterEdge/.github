### 一、项目简介

- **仓库用途**: 维护 FasterEdge GitHub 组织级公开资料,包括组织主页、公共图片和组织配置。
- **组织主页**: GitHub 会将 [`profile/README.md`](profile/README.md) 渲染为 FasterEdge 组织首页。
- **资源目录**: `images/` 存放组织主页引用的公共图片资源。
- **内容边界**: 本仓库只保存适合公开展示的组织资料,不保存项目密钥、内部文档、个人信息或部署凭据。

### 三、维护原则

- **事实一致**: 组织主页中的版本、功能和仓库状态应以对应源码仓库为准。
- **同步更新**: 新增、移除或调整核心项目时,同步更新组织主页中的仓库导航和版本快照。
- **公开安全**: 不在组织主页、图片元数据、提交信息或示例中写入密钥、令牌、真实生产地址和个人敏感信息。
- **链接检查**: 更新文档后检查仓库链接、图片路径和 Markdown 表格是否正常渲染。
